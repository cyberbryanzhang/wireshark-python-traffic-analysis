## Abstract

Modern networks continuously generate large amounts of traffic, making it increasingly important for security practitioners to understand how to recognize suspicious communication patterns.

This project introduces beginner-friendly approaches for:

- Inspecting packets with Wireshark
- Identifying unusual traffic behavior
- Performing lightweight traffic analysis using Python
- Understanding foundational network security workflows

The repository focuses on educational clarity and practical learning rather than advanced threat research or production-level detection engineering.
